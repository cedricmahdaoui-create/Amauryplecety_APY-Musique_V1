Gérer les instruments à vendre

Ajoutez, modifiez, réordonnez ou retirez les instruments. Rien n'est publié tant que vous n'avez pas enregistré le fichier catalogue.json (voir en bas de page).

Enregistrer les modifications

  2. Placer ce fichier dans le dossier assets/data/ du site (il remplace l'ancien).
    • Hébergement FTP (OVH, o2switch…) : envoyer le fichier dans www/assets/data/.
    • Netlify (glisser‑déposer) : re‑déposer le dossier complet du site.
    • Netlify + dépôt Git : voir l'éditeur en ligne dans /admin/cms.html (§ README).
  3. Le catalogue est à jour en quelques secondes (vider le cache si besoin).
